`source-provenance.json` records hashes of the local source before annotation. Code-token/AST comparisons check that the two C++ programs and analyzer retain their statements. The archived results were measured with the old flat layout, not generated by the reorganized launchers.

The repository also adds named helpers for earlier manually entered connectivity/hostname/hello checks and a raw-results verifier. These are reproducibility aids, not a fabricated historical command record.

For a fresh VM checkout, use `~/heat-project-repo` on every VM and build locally. Keep the original `~/heat-project` and private raw export. This layout change is not a request to reinstall Ubuntu, recreate the tailnet, overwrite SSH keys or repeat hours of measurements.
