The walkthroughs use the allocation from the experiments they describe. The
historical Part 0 captures used 2+2+2 vCPUs. The final Part 3 and 4 studies used
4+2+2. Strip fields were compared byte-for-byte at P=1–4. The block study
also compared fields at P=8. Both layouts timed runs at P=8.

Use the [final report](../final-report/final-report.pdf) and
